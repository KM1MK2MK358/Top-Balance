# Top Balance

## About the Script
Curious who's loaded or totally broke? TopBalance shows the full wealth map with 6 smart filters: Richest & Poorest overall, online, and offline. No hassle—open it, see your exact rank in seconds, and know where you stand in a clear, simple UI.

## Requirements
- [Skript](https://modrinth.com/plugin/skript) - For running the script.
- [CommandPanels](https://commandpanels.net/home) - For creating the UI dialogs.
- [Vault](https://www.spigotmc.org/resources/vault.34315/) - For managing the economy.
